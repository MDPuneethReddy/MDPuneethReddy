#### 🔬 Featured

**[cryoem-files-mcp](https://github.com/MDPuneethReddy/cryoem-files-mcp)**: an MCP server that lets Claude inspect, validate and convert cryo-EM files on your own machine.
It catches a common silent preprocessing mistake: a gain reference in the wrong orientation. It does this by testing all 8 rotations and flips against the raw frames and scoring the match statistically.
`Python` · `MCP` · `numpy` · 9 tools · ~2.5k lines of tests · ships as a Claude Code plugin

**[LLM Input Guard](https://github.com/MDPuneethReddy/llm-safe-extension)**: a Chrome extension that flags PII and credentials while you type into ChatGPT, Claude or Perplexity, before you hit send. The check runs on a local LLM inside the browser, so nothing leaves your machine.
`TypeScript` · `WebLLM` · `WebGPU` · Phi-3.5-mini · Manifest V3

**[Portfolio v2](https://github.com/MDPuneethReddy/portfolio)**: a Netflix-style portfolio with a profile picker, hover previews, a "trailer," and a walking mini-me guide. → [mdpuneethreddy.com](https://mdpuneethreddy.com)
